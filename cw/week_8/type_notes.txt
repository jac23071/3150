	-static_cast
		+can convert between compatible types (checks at compile time)
	-const_cast

		+ typical for legacy APIs that don't use consts
		+It is uncommon and usually unsafe to remove the const restriction from a const var.
		+modifying a var that was og a const causes undefined behaviour
		+adding a const restriction is very safe tho.		-reinterpret_cast<>
		+ can convert wildly differnt types
		+ extremely low-level and works based on bit

		+ good for low-levek gardware programming
